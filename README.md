# РАКОВАРЪ — цифровая витрина и клуб (preview)

Отдельный проект для цифрового канала компании «Раковаръ»: витрина, каталог, клубные билеты, реферальные приглашения, игровые механики и административный центр.

## Состав сборки

Полный исходный пакет находится в `source_bundle.tar.xz`. Внутри — Flask-приложение, каталог из 62 демонстрационных позиций, шаблоны, CSS/JS, MAX client/bot/auth, SQLite schema, tests, scripts и проектная документация.

Для просмотра исходников скачайте архив из репозитория и распакуйте его. Файлы не разнесены по корню GitHub, чтобы передать сборку одним проверяемым артефактом через GitHub API; после распаковки структура проекта обычная.

## Быстрый локальный запуск

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python app.py
```

Откройте `http://127.0.0.1:8080`.

## Render

Корневой `render.yaml` создаёт отдельный сервис `rakovar-preview` во Frankfurt на Free instance. На этапе build Render распаковывает `source_bundle.tar.xz`, устанавливает зависимости и запускает Flask/Gunicorn через `start_render_preview.py`.

## Границы preview — прочитать до использования

- `DEMO_MODE=true`: это демонстрация, не коммерческий магазин и не публичная оферта.
- Цены и наличие в каталоге не подтверждены компанией; в карточках сохранены флаги проверки.
- Реальный приём платежей, возвраты, доставка, CRM и автопубликация в соцсети не подключены.
- SQLite на Render использует временную файловую систему; данные могут исчезнуть при перезапуске/пересоздании сервиса.
- Админ-вход отключён, пока владелец не задаст `ADMIN_PASSWORD_HASH` в Render Environment.
- MAX bot/Mini App не подключены, пока владелец не задаст реальные секреты и не проверит API.
- Все изображения — оригинальные SVG-иллюстрации-заглушки, не фотографии продукции.
- Не вводите реальные данные покупателей и не используйте preview для оформления реальных заказов.

## Проверки

Перед упаковкой прошли:
- `python scripts/validate_preview.py`;
- `python -m unittest tests.test_preview_core -v` (7 тестов);
- Python AST/syntax и Node.js syntax checks.

Flask integration suite не была выполнена в среде упаковки, так как Flask/Werkzeug отсутствовали. Её нужно прогнать в CI после установки `requirements.txt`.

## Production gate

Перед коммерческим запуском: подтвердить каталог/цены/состав/аллергены/фото/наличие/адреса/доставку; перейти на PostgreSQL и миграции; настроить backup/restore, роли/MFA, платёжные webhooks и возвраты; перевести MAX на webhook; подключить официальные API социальных сетей; утвердить правила клуба и конкурсов; пройти security, privacy, accessibility и E2E review.
