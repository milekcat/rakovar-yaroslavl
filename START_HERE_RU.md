# РАКОВАРЪ — быстрый локальный запуск + MAX

Это локальный preview. Постоянный домен и постоянный хостинг не нужны. Компьютер должен оставаться включённым, пока работает Mini App.

## Что уже подготовлено

- Бот MAX `@id7606139934_5_bot` и клиент MAX Bot API (`platform-api2.max.ru`).
- Команды `/start`, `/catalog`, `/club`, `/tickets`, `/id`, `/help`.
- Витрина и административная панель `/admin/login`.
- 62 демонстрационные позиции в 13 категориях из публичных меню/карточек. Все цены и остатки требуют подтверждения «Раковаръ».
- Начисление клубных билетов: правило по умолчанию 1 билет за 1 000 ₽ подтверждённой оплаты; дополнительные билеты могут выдаваться за промоакции и конкурсы по заранее заданным правилам.
- Списание билета при запуске игровой механики. Покупка билетов/шансов и денежные ставки отсутствуют.

## 1. Подготовка Windows

Установите Python 3.11+ и откройте PowerShell в папке проекта.

```powershell
Copy-Item .env.example .env
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Откройте `.env` и заполните локально:

```dotenv
MAX_BOT_TOKEN=ВСТАВЬТЕ_СЮДА_ТОКЕН_ИЗ_MAX
MAX_BOT_USERNAME=id7606139934_5_bot
MAX_MINIAPP_URL=
FLASK_SECRET_KEY=длинная_случайная_строка
ADMIN_PASSWORD_HASH=хеш_пароля_админки
COOKIE_SECURE=false
DEMO_MODE=true
```

Не присылайте токен в чат, не помещайте его в скриншоты и не загружайте `.env` в GitHub. В предоставленном скриншоте токен замаскирован, получить его оттуда невозможно. Если токен уже где-либо публиковался открыто — отзовите и выпустите новый в MAX.

Создать хеш пароля админки:

```powershell
.\.venv\Scripts\python.exe -c "from werkzeug.security import generate_password_hash; print(generate_password_hash(input('Admin password: ')))"
```

Скопируйте выведенный хеш в `ADMIN_PASSWORD_HASH`. Сам пароль не сохраняйте в `.env`.

Для `FLASK_SECRET_KEY` можно сгенерировать случайное значение:

```powershell
py -3 -c "import secrets; print(secrets.token_urlsafe(48))"
```

## 2. Запустить сайт и бота

```powershell
.\run_local.ps1
```

Сайт: `http://127.0.0.1:8080`
Админка: `http://127.0.0.1:8080/admin/login`
Бот: `https://max.ru/id7606139934_5_bot`

Напишите боту `/start`, затем проверьте `/catalog`, `/club`, `/id`. Команда `/id` покажет ваш MAX user ID: добавьте его в `.env` как `MAX_ADMIN_USER_ID`, чтобы получать уведомления о тестовых заказах. При успешной авторизации в окне бота появится `MAX bot connected`.

## 3. Подключить Mini App без постоянного хостинга

MAX не открывает локальный `127.0.0.1`: Mini App требует публичный HTTPS URL. Для временной демонстрации можно использовать Cloudflare Quick Tunnel.

1. Установите `cloudflared` по официальной инструкции Cloudflare.
2. Оставьте Flask запущенным и откройте новое окно PowerShell:

```powershell
cloudflared tunnel --url http://127.0.0.1:8080
```

3. Скопируйте выданный `https://....trycloudflare.com`.
4. В `.env` задайте `MAX_MINIAPP_URL=https://....trycloudflare.com`.
5. Остановите и снова запустите `run_local.ps1`, чтобы бот перечитал URL и зарегистрировал кнопку открытия приложения.
6. В MAX для бизнеса → Чат-боты → `Раковаръ Ярославль` → Настройки → Мини-приложение вставьте тот же HTTPS URL, выберите кнопку «Открыть» и нажмите «Сохранить».
7. Откройте чат с ботом и запустите мини-приложение.

Quick Tunnel временный: адрес изменится после перезапуска туннеля. При смене адреса обновите `MAX_MINIAPP_URL`, настройки бота MAX и перезапустите локальные процессы. Пока компьютер, Flask и cloudflared работают, приложение доступно по временному HTTPS адресу.

## 4. Что проверять в демонстрации

1. Открыть витрину, поиск, категории и карточку товара.
2. Добавить позиции в корзину, изменить количество, получить серверный расчёт.
3. Пройти тестовое оформление — это заявка preview, не реальный оплаченный заказ.
4. Войти в админку, посмотреть заявки, каталог, промо, призы, конкурсы, контент-план, интеграции и аналитику.
5. В MAX проверить `/club` и `/tickets`; в Mini App — авторизацию и баланс клуба.
6. Проверить игровую механику: списание билета, выдачу приза и историю.

## 5. Ограничения preview

- `DEMO_MODE=true`: тестовые заявки, тестовые балансы/призы. Не принимать реальные платежи и персональные данные клиентов.
- Каталог собран из публичных меню и агрегаторов; цены, состав, граммовки, наличие, доставка и изображения должны быть подтверждены владельцем бренда.
- Товарные фото агрегаторов не копировались. Используются локальные категорийные изображения-заглушки и логотип, предоставленный в материалах проекта.
- MAX Mini App проверяет подписанные `initData` на backend; не используйте `initDataUnsafe` как доказательство личности.
- Long Polling — только для локальной разработки. Официальная документация MAX рекомендует Webhook для постоянного окружения.
- Лотерейные/конкурсные механики в preview бесплатные и демонстрационные. До реального публичного запуска правила, связь участия с покупками, обработку ПДн и призовой фонд должен проверить юрист.
